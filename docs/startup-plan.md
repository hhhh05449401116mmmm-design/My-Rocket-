# افتتاح Crazy Rocket وجاهزية صور الأزرار

## النطاق والمرجع

الصورة IMG_3935 هي اللعبة الفعلية. تسجيل ScreenRecording_10-08-202614-55-26_1.mp4 مرجع **لفكرة شاشة افتتاح فقط**، وليس لعبة المستخدم. لا تُنسخ منه رسومات Chance أو اسمه أو تصميمه. الأساس هو نسخة اللعبة `bd7dcf9` المنشورة على Railway. التطوير محلي، ولا يُرفع إصدار جديد إلى main قبل الموافقة عليه لأن الرفع يطلق النشر التلقائي.

## السبب والحل

أزرار Rocket وPVP وPlay Hub تستخدم Canvas لا ترسم فن الزر حتى يفك المتصفح أول إطار من الفيديو المخفي. الصناديق أيضًا تستخدم فيديو دون صورة بديلة مرئية. ملفات silent المنشورة سليمة وتعيد HTTP 206، لكن وصول إطارها على الهاتف قد يتأخر؛ لذلك مؤقت افتتاح ثابت وحده لا يصلح المشكلة.

تضاف شاشة HTML/CSS خفيفة تستخدم **شعار Crazy Rocket الموجود** `icon-180.png` على الخلفية الكحلية والبنفسجية الأصلية، واسم اللعبة ومؤشر مرحلتين فعليتين: جاهزية صور الواجهة، وانتهاء التهيئة والمصادقة. الشعار يطفو بهدوء؛ الحركة تُلغى مع prefers-reduced-motion. الشاشة تحترم Safe Area، ولا تستخدم فيديو افتتاح ثقيلًا أو رسومات جديدة.

تُستخرج 16 صورة WebP من أول إطار للفيديوهات الأصلية: 3 للأزرار و13 للصناديق، في `assets/startup-posters/`. نفس النسب والفن، دون تعديل أي ملف فيديو أصلي أو حركته. الصورة خلف Canvas تبقى ظاهرة إذا تأخر الفيديو أو تعذر autoplay؛ وعند فك الفيديو ترسم Canvas فوقها. يوجد اسم الزر خلف الصورة إذا فشل تحميلها أيضًا. الصناديق تستخدم صورًا مطابقة ويبقى فيديوها مخفيًا حتى playing، فلا يظهر زر تشغيل نظام iOS بدل الفن. ترتبط المستمعات فور إنشاء البطاقات، مع تعافٍ إذا سبق بدء التشغيل ربط المستمع.

## التوقيت والأمان

- انتظار الصور الثلاث الأساسية وأول صورتين للصناديق، **لا تحميل جميع الفيديوهات** أو المخزون أو الأصول البعيدة.
- إنهاء الافتتاح بعد اكتمال المرحلتين، مع حد عرض أدنى لطيف 650 مللي ثانية. لا عدّ شكلي مدته عدة ثوانٍ.
- حد انتظار أقصى 8 ثوانٍ يبدأ من تشغيل متحكم الافتتاح، لا من انتهاء الشبكة. إذا تعثرت المصادقة، تفتح الواجهة بالصور والاتصال يستكمل وفق المسار الأصلي، **دون اعتبار المستخدم مصادقًا**.
- تأجيل SDKs المساعدة TonConnect وLottie عن أول رسم. يبقى ترتيب Telegram SDK كما كان لأن الكود الحالي يقرأ هوية المستخدم منه.
- لا تغيير في server.js أو database.js أو قيم الأرصدة أو اختيار الفائز أو قواعد PVP أو الهدايا. نقطة التشغيل الإنتاجية تبقى `node server.js`، ولا يدخل غلاف معاينة إلى الإصدار.

## الملفات

- `index.html`: شاشة الافتتاح، بوابة التهيئة، الصور البديلة، وربط الفيديو بالصناديق.
- `assets/startup-posters/`: صور مطابقة للفيديوهات الحالية، تُخدم عبر static الأصلي.
- `test/startup-ui.test.js`: قواعد الانتظار والمهلة وتنظيف مستمعات الصور وربط تشغيل الصناديق وصون المصادقة.
- أدلة الاختبار المحلي تحت `/home/ubuntu/video-work/rocket-startup-browser/`، ليست كود تشغيل حيًا.
