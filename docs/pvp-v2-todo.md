# نتائج PvP المطلوبة — نسخة الفيديو الأحدث

- [x] الدائرة العلوية تعرض رهانات TON أو Gift في خانات داكنة مقسّمة. الخانات الفارغة تحمل CRAZY / ROCKET بدل صور اللاعبين. لا avatar للاعب داخل الدائرة؛ رموز TON/الهدايا تستخدم لتمثيل الرهان فقط.
- [x] الدائرة تبقى تدور بسرعة ثابتة عبر WAITING وCOUNTDOWN وLIVE وRESULT، ولا تتوقف على الفائز ولا تتسارع عند انتهاء الوقت.
- [x] شريط أسفل الدائرة يعرض أسماء وصور ونسب المشاركين الفعليين. يبقى ثابتًا قبل انتهاء العدّ، ثم يتحرك إلى اليسار أثناء LIVE تحت مؤشر وسط ثابت، ويتباطأ إلى بطاقة فائز الخادم عند RESULT. تكرار البطاقات عرضي فقط؛ العدد والقائمة والرهانات لا تضيف مشاركين.
- [x] لا لاعبين وهميين أو أرصدة اختبار في شيفرة الإنتاج. البيانات تأتي من API/SSE الحقيقي ومن حسابات Telegram الأصلية؛ خصم TON وقفل Gift وتحديد الفائز وتسويته من محرك اللعبة الموجود دون تغييره.
- [x] المحافظة على Safe Area والتنقل والقائمة على الهواتف. اجتاز فحص المتصفح 390×844 و360×640 و375×667 و430×932 مع عدم خروج الزر عن التنقل وبقاء مساحة قائمة اللاعبين.
- [x] إعادة اتصال SSE مع polling تعمل، وتُوقف الموارد عند الخروج من PvP. فحص المتصفح أكد توقف شريط الفائز في الوسط وبقاء دوران الدائرة بعدها.
- [x] اعتماد نتيجة فحص استعادة COUNTDOWN/LIVE/RESULT دون فقد رهان أو إعادة تسوية. اجتازت الاختبارات 43/43.
- [ ] الإصدار الحي: موافقة exact commit وpush إلى main الذي قد ينشر تلقائيًا على خدمتي Railway، ثم التحقق من إصدار خدمة Crazy1Rocket_Bot https://my-rocket-production-150d.up.railway.app . لا غلاف معاينة Manus ولا قاعدة اختبار ولا .env في الإصدار.
- [ ] إكمال وصول Railway Project Token المفقود في بيئة التنفيذ، والتحقق من خدمات/نسخة النشر من API قبل ادّعاء تشغيل النسخة داخل Telegram.
