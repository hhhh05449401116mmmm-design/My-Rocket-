# نتائج النسخة الجديدة

- [x] يقبل PvP الرهانات طالما لم تبدأ الجولة: WAITING وCOUNTDOWN. رهان شخص واحد يعرض اسمه وقيمته ونوع TON أو Gift وكل مشاركته، ولا يبدأ الجولة أو العدّ حتى يراهن شخص ثانٍ مختلف؛ يبدأ بعدها20ثانية. إعادة التشغيل لا تفقد رهان اللاعب الوحيد ولا تقفل هديته في جولة مهجورة، وبعد النتيجة تنشأ جولة انتظار لا عدّ تلقائي.
- [x] يُزال زر رجوع PvP الداخلي؛ زر السهم أعلى اليمين يصبح ساعة خطية تفتح PVP History مثل المرجع، مع All Games وMy Games، ووقت/رقم الجولة وعدداللاعبين والفائز ومجموعالجوائز ونسبةالفائز ومجموعTON وصورالهدايا الحقيقية، وسجلقديمةفعليةفقطومزيدللصفحات.
- [x] زر Telegram في الرئيسية إغلاق، وخارجها رجوع. يغلق الصندوق أو النافذة الأعمق ثم يعود للشاشة السابقة؛ سجل→PVP→الرئيسية، ألعابPlayHub→PlayHub→الرئيسية، باقيالأقسام→الرئيسية. لا يغلقMiniAppبدلرجوعولا يكررمستمعالضغط.
- [x] سرعة الدائرة أقل قليلًا:36درجة/ثانية بدل42، ثابتة في المراحل، دون تغييرحركةالشريط أو الفائزوالتسوية أو بقيةتصميماللعبة.
- [ ] نسخةجديدةمفحوصةبالاختباراتالمؤقتة،تحتاجموافقةSHAجديدقبلmainوالنشرالتلقائي. لا نشرغلافمعاينةأومفاتيحأوبيناتتجريبيةإلىRailway،لاresetقاعدة أوvolume أوdomains.
