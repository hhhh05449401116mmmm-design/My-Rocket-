# PvP — انتظار لاعبين وسجل الجولات وتنقل Telegram

نطوّر النسخة الأصلية المنشورة f48f116 في /home/ubuntu/projects/crazy-rocket، ولا نعدّل موقع Manus المستقل أو قاعدة Railway الحية أثناء التطوير. أسلوب الواجهة الداكنة والأصفر/السماوي وشرائط اللاعبين يبقى كما هو. الصور المرفوعة مرجع لزر ساعة خطّي ولصفحة تاريخ ببطاقات؛ تستخدم الأصول الموجودة، بلا صور أو لاعبين مولّدين.

## التنفيذ والتصميم

تبدأ الجولة WAITING بلا deadline. رهان TON أو Gift الأول يُخصم/يُقفل وفق المنطق الحالي ويظهر فورًا بقيمته واسم صاحبه ونسبته. لا يبدأ عدّ20ثانية إلا بوجود مشاركين ACTIVE لهويتين مختلفتين؛ الرهانات مسموحة في WAITING وCOUNTDOWN ومقفلة عند LIVE/RESULT. استعادة COUNTDOWN قديمة بلا لاعبين اثنين تعيد نفس الجولة إلى WAITING دون فقدان رهان، بينما LIVE جارية تُستكمل ولا تُعاد تسويتها. لا تغيير لمعادلة الفائز أو نقل الملكيات أو schema. الانتقال ذري بشرط phase WAITING حتى لا تعيد طلبات متزامنة deadline.

نزيل زر الرجوع الداخلي من شريط رأس PvP ونبقي مساحة العنوان وسطًا. زر اليمين يصبح SVG ساعة/تاريخ أبيض، ويفتح شاشة PVP History ضمن اللعبة تحتوي All Games وMy Games؛ بطاقات داكنة مستديرة تعرض التاريخ، رقم الجولة، عدد المشاركين المختلفين، اسم وصورة/حرف الفائز، إجمالي الوعاء ونسبة فوزه، ومجموع TON ورموز الهدايا الموجودة في رهانات الجولة. My Games يفلتر بمستخدم المصادقة على الخادم لا userId في query. سجل RESULT الفعلية فقط، مع pagination محدودة. لا سجل مختلق ولا أسرار seed أو البيانات الخاصة.

الدائرة تصبح36درجة/ثانية بدل42، تباطؤخفيف ويبقى المعدل نفسه في جميع المراحل؛ حركة شريط اختيار الفائز لا تتغير.

زر Telegram الأصلي يتحكم فيه BackButton.show()/hide(). يُظهر الرجوع عند صفحة/لعبة/نافذة خارج الرئيسية. الضغط يغلق أعمق نافذة أولًا، ثم سجلPvP→PvP→الرئيسية؛ ألعابPlayHub→PlayHub→الرئيسية؛ ملف/هدايا/متصدرين→الرئيسية؛ صندوقمفتوح→الشاشة السابقة. عند الرئيسية وحدها يُخفىBackButtonليعودإغلاقTelegram. MutationObserverخفيف علىclass/hiddenيربط تغييرات الشاشات والنوافذ القائمة بدون إعادة كتابة محركات الألعاب أو اعتراض المدفوعات. دوال الإغلاق الأصلية تبقى مسؤولة عن التنظيف.
